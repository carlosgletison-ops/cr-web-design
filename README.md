# CR web design — O Ajuste Fino *

Landing Page institucional e estratégica da **CR web design** (Carlos Gletison), desenvolvida com foco em alta performance, minimalismo conceitual e conversão.

## ⚡ Tecnologias & Conceito

- **HTML5 Semântico & CSS3 Puro**: Layout responsivo, animações fluidas e efeito *liquid glass*.
- **JavaScript Vanilla**: Engine de zoom vetorial no scroll e transições dinâmicas sincronizadas com `requestAnimationFrame`.
- **Identidade Conceitual**: Narrativa baseada no asterisco (`*`) como operador de correção técnica e multiplicação de autoridade.

## 🚀 Como Visualizar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.
